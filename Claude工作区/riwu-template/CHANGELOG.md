## v0.4

**核心改动：让观众「记住名字」。** 按 v0.3 反馈（中文应在前、名字没记住就开始讲、知识串不起来）重做讲解页节奏。

| # | 问题 | v0.4 |
|---|---|---|
| 1 | 中文放在中间，观众没有「已知」的锚点 | `bridge`（默认「中」）最先出现，只停 2.4 秒、不讲重点，标「你熟悉的叫法」；日语紧接着作为主角 |
| 2 | 名字一闪而过就开始讲解，记不住 | 新增「名字」步：单独停 2.4–3.6 秒；名字 / 读音 / 字面在讲解时**一直留在屏上** |
| 3 | 原卡名称切片大小、清晰度不一 | `word` / `reading` 用 Noto Serif CJK 原生排版（按语言选日/韩/简/繁字形），最大 170px |
| 4 | 名字是整块，看不出构词 | `parts`：把名字拆成几段，每段下面标意思（如 カップ=杯子 / スリーブ=袖子） |
| 5 | 各语言各讲各的，串不起来 | `parts[].link`：后面的语言遇到前面出现过的同一意思，自动出「又见面了」行，标出是哪种语言的哪一段 |
| 6 | 日语讲完就过去了 | 日语末尾加「还记得它叫什么吗？」回忆步：名字先模糊，约 55% 处揭晓（`recall`） |
| 7 | 结尾「打码」只是装饰 | 结尾各语言名字模糊 → 倒数后逐个揭晓，给「不回看你记住了吗」一个答案 |
| 8 | 重点块太长读不完 | 默认最多：中文 0 块、日语 2 块、其他 1 块（`max_focus`）；按 10 字/秒估阅读时间，不够就报 ⚠ 阅读时间 |
| 9 | 每块重点前要先「看懂」整段 | `focus[].note`：≤26 字的一句提示，金色竖条放在面板下 |
| 10 | 每行黄色荧光笔太花 | 面板默认不扫荧光笔；强调只留在名字拆段和「又见面了」上 |
| 11 | 切片带着卡片底色，出现色块「补丁」 | 切片改成只留墨迹的透明图（局部背景估计后抠出），叠在统一的面板纸色上 |
| 12 | 重排断行：英文词中间断开、汉字偏旁被拆、字母 s 被当成逗号、ff 连字丢一半、行尾孤字 | 断点只选词间 / 字间空隙；偏旁并回整字；标点判定看后面的留白；小连通域跟着相邻大字走；孤字/差一点放下时自动缩小重排（最多 3 次，正文 ≥46px） |
| 13 | 复盘只是切片罗列 | 复盘用原生名字，`insight_links` 指定的那段（如「袖」）亮色高亮 |

**字段变化**：新增 `bridge`、`cards[].word`（必填）、`reading`、`parts`、`focus[].note`、`max_focus`、`insight_links`、`recall`；`title` / `name` 改为可选（不再必需）。
**参数变化**：`read_units_per_sec` 14→10，`focus_hold` [3.0,4.8]→[3.0,5.4]，新增 `name_hold_anchor` / `name_hold_bridge` / `recall_beats` / `recap_beats` / `outro_beats`、`layout.word_*`、`lang_font`、`colors.card`、`text.bridge/recall/link`；`text.answer` 改为「重点记」。
