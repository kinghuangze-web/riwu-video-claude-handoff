# 人工验收清单（自动检查通过后，人再看一遍）

自动检查（`qc/report.md`）只能保证"技术上没坏"。下面这些要人看，建议直接用手机全屏播放 `out/<期>.mp4`。

## 看 `build/<期>/qc/lifts.png`（出片前）
- [ ] 每块抬出来的字都完整，没有被切半个字
- [ ] 没混进相邻栏的内容、分隔线、照片边、页眉
- [ ] 重排后行首没有「，。、」
- [ ] 每块重点不超过 6 行；字看起来不小
- [ ] 红线（x=966，y 1000–1600）右边没有内容
- [ ] 大标题（hero）只有名称这一行：下面没有别的行的半个字、变音点、尾巴
- [ ] 面板里没有卡片底色色块，也没有被抠掉的浅色笔画
- [ ] 英文没有在单词中间断行，汉字偏旁没被拆开
- [ ] 名称区的小图标（喇叭/书本等）没被当成字放大（有就加 `hide`）

## 看成片（第一遍：当观众）
- [ ] 第 1 秒就知道这条视频在问什么
- [ ] 中文先出现、很短；日语名字停留时能默念一遍
- [ ] 讲解时还看得到名字、读音、拆段意思
- [ ] 「又见面了」连得对：同一个意思，语言和那段都标对
- [ ] 日语回忆步：模糊时能先想起来，揭晓时有「对，就是它」的感觉
- [ ] 结尾揭晓的名字和前面一致
- [ ] 每块重点在消失前能读完（读不完 → 框少一点）
- [ ] 换场顺，没有黑帧/空白帧/闪烁
- [ ] 四种语言不觉得重复无聊
- [ ] 复盘那句跨语言发现说得通、有意思，而且卡片上能找到依据
- [ ] 结尾想在评论区打字

## 看成片（第二遍：挑毛病）
- [ ] 照片里没有被放大出来的页眉文字、logo、页码
- [ ] 被讲的那个小东西（subject）每一页都看得见，没被 HUD 或标题盖住
- [ ] 日语（入口）第一个出现；复盘高亮的那几行和 insight 说的是同一批语言
- [ ] 字没有发虚到难受
- [ ] 平台界面（顶栏、右侧按钮、底部标题）不挡任何字
- [ ] 声音：揭晓铃、风声、滴答的音量自然，不刺耳；配乐不抢
- [ ] 总长 30–50 秒

## 内容
- [ ] 讲解文字都是原卡像素；`word` / `reading` / `parts[].t` 和卡上一字不差（包括冠词、长音、空格）
- [ ] `parts[].m`、`note` 只是卡上信息的摘取/缩写，没有新增知识
- [ ] `meaning` / `insight` 每一句都能在卡上找到依据
- [ ] 发现卡片本身可疑的地方，写在交付说明里（不要改卡）
