# template/style.json 参数说明（v0.4）

> 这些是**整个系列**的参数，改了所有期都会变。每期不要改；要改风格时改这里，并用 M006 重新出片对比。

## 顶层

| 键 | 当前值 | 含义 |
|---|---|---|
| `fps` / `width` / `height` | 30 / 1080 / 1920 | 成片规格 |
| `bpm` | 100 | 配乐速度；所有停留时间都会对齐到整拍（1 拍 = 18 帧 = 0.6 秒） |
| `ink_threshold` | 140 | 判断"这是文字墨迹"的灰度阈值（0 黑–255 白）。卡片文字很浅时调高 |
| `read_units_per_sec` | 10 | 阅读速度估计：每秒读多少"字宽单位"。调小 = 每块停更久；需要的时间超过上限 12%（例句 40%）会报 ⚠ 阅读时间 |
| `name_hold` | [2.4, 3.0] | 普通语言「名字」步停留秒数下限/上限（有「又见面了」+0.6） |
| `name_hold_anchor` | [3.0, 3.6] | 主角语言（日语）名字步 |
| `name_hold_bridge` | [2.4, 2.4] | 过渡语言（中文）名字步 |
| `focus_hold` / `focus_hold_other` | [3.0, 5.4] | 重点面板停留秒数下限/上限（主角 / 其他语言） |
| `recall_beats` | 4 | 日语回忆步拍数（55% 处揭晓） |
| `recap_beats` / `outro_beats` | 6 / 7 | 复盘 / 结尾拍数 |
| `lang_font` | 日→JP、韩→KR、粤→HK、繁→TC | 名字用 Noto Serif CJK 的哪套字形；其他语言用 SC |
| `kind_label` | | `focus.kind` → 显示的小标题 |

## layout（像素，基于 1080×1920 画面；v0.3 重排）

| 键 | 当前值 | 含义 |
|---|---|---|
| `photo_band` | 760 | 讲解页照片区高度。下沿约 250px 渐隐进纸面；被讲的那个小东西（`subject`）会自动放进照片露出部分的中间 |
| `hero_x` / `hero_w` / `hero_h` | 64 / 952 / 200 | 大名称（原卡最大那一行，底色归一后 multiply 叠在纸上）的位置和最大尺寸 |
| `meaning_h` | 78 | 「字面」行占的高度（深色「字面」小章 + 54px 意思 + 荧光笔） |
| `panel_x` / `panel_w` | 64 / 900 | 面板左边和最大宽度。右边缘 ≤ 964，避开平台右侧按钮列 |
| `panel_inner_w` / `panel_inner_h` | 832 / 980 | 面板内容最大宽 / 高；太宽的行自动重排（合并卡片硬换行，重新填满整行） |
| `panel_pad` | 34 | 面板内边距（行尾标点最多可伸进右内边距 22px） |
| `target_text_px` / `sub_text_px` | 50 / 48 | 重点正文 / 名称副行的目标字高。手机上 ≥ 40px 才看得清 |
| `zoom_min` / `zoom_max` | 1.0 / 3.0 | 文字放大倍数范围（预先 Lanczos 放大 + 锐化，3 倍仍清楚） |
| `content_bottom` | 1580 | 面板底边最低到哪里；1600 以下是平台文案区 |
| `shift_max` | 430 | 内容太多时，整页（照片 + 标题 + 面板）最多向上推多少 |
| `drop_max` / `drop_keep` | 340 / 90 | 内容很少时，整页最多向下放多少（照片区随之变高），以及底部至少留多少 |
| `hook_bottom` / `hook_q_h` | 1560 / 440 | 开场问题面板底边 / 问题句最大高度 |
| `recap_top` / `recap_bottom` | 420 / 1450 | 复盘列表的上下边界（每行 ≤ 250px） |
| `transition` | 8 | 场景重叠推镜的帧数 |
| `ink_threshold` | 140 | 判定「墨迹」的灰度阈值（找行、找字间空隙、清理框边半个字都用它） |
| `word_max` | 170 | 名字最大字号（放不下自动缩小） |
| `word_drop_max` / `word_bottom` | 560 / 1500 | 只有名字、没有面板时，名字组最多下移多少 / 底边最低到哪里 |

v0.2 的 `panel_cx`、`name_top`、`focus_bottom`、`panel_min_top`、`hook_panel_top`、`recap_h`、`name_min_top`、`photo_h`、`wrap_indent` 已删除。

## colors

`paper` 纸底、`paper2` 次纸色、`ink` 主文字、`sub` 次文字、`accent` 荧光笔/语言章、`accent2` 强调（进度条、揭晓、描边）、`accent_text` 金色文字（比 accent2 深一档，保证奶白底上对比度 ≥3）、`sun` 山形装饰的太阳。全部取自原卡片配色。`card` = 面板纸色 #FBF7F0（切片只留墨迹，叠在这个颜色上）。

## 声音（scripts/audio.py，不在 style.json 里）

和弦进行 Fmaj7–Em7–Dm7–Cmaj7，开场后半段进鼓。音效只在 `plan.events` 上发声：

| 事件 | 声音 | 什么时候 |
|---|---|---|
| `start` | — | 第 0 帧 |
| `whoosh` | 风声 | 开场拉开、每次换场 |
| `tick` | 滴答 | 3·2·1 倒数 |
| `reveal` | 三音上行铃 + 低音 | 第一种语言揭晓、复盘的跨语言发现 |
| `thump` | 低音落点 | 其他语言名称、结尾两行大字 |
| `pop` | 弹出 | 重点面板、复盘每一行 |
| `type` | 键盘声 | 评论框打字 |

整片响度统一到 −16 LUFS。换自己的音乐：`./render.sh episodes/M006 --bgm 你的.mp3`（音效照样叠上去）。
