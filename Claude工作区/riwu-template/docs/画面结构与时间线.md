# 画面结构与时间线（v0.5；讲解式以 M006 为例，单位：帧 @30fps）

```
0 ──── 126 ── 198 ──────────────────── 612 ──────── 864 ──────── 1116 ── 1224 ──── 1350
│开场 4.2s│中 2.4s│ 日语（主角）13.8s       │ 英语 8.4s  │ 德语 8.4s  │复盘3.6s│结尾4.2s│
            名字3.0│为什么这么叫3.0│例句5.4│回忆2.4
```

- 顺序：`bridge`（默认「中」）→ `anchor`（默认「日」）→ 其余按卡片顺序。
- 中文：只有「名字」步（2.4 秒），标「你熟悉的叫法」，不讲重点（`max_focus` 默认 0）。
- 日语：名字 3.0–3.6 秒 → 最多 2 块重点（3.0–5.4 秒）→ 回忆 4 拍（2.4 秒）。
- 其他语言：名字 2.4–3.0 秒（有「又见面了」时 +0.6 秒）→ 1 块重点。
- 停留时间按字数自动算（10 字宽单位/秒），对齐整拍（1 拍 = 0.6 秒）。算出来超过上限 12% 以上会报 ⚠ 阅读时间。
- 相邻场景重叠 8 帧推镜。全片约 45 秒（M006 45.0 / M005 45.6 / M004 45.6）。

## 竖屏分区（1080×1920）

```
y    0–220   平台顶栏区：只有照片
y  236–302   HUD：左「日物图鉴 M.006」，右语言圆点
y  330–~700  照片露出区：subject 自动放在这段中间
名字步       语言章 + 标签（重点记 / 你熟悉的叫法）→ 大字名字（≤170px）→ 读音 → 拆段意思（或「字面」行）
             →「又见面了」行（语言简称 + 那一段）；内容少时整组下移到画面中部
讲解步       名字组上移缩小但保留；下面是重点面板（原卡切片，透明墨迹叠在 #FBF7F0 纸上）+ note 一行
回忆步       名字模糊 +「？」+「还记得它叫什么吗？」→ 55% 处火花揭晓
y 1600 以下  平台标题/文案区：只放装饰
x  964 以右  平台按钮列（y 1000–1600）：不放内容
```

## 各场景细节

**开场（7 拍）**：第 0 帧 = 问题面板 + 主体特写 → 三个「?」→ 拉开看全貌 →「先猜一下」+ 圆环倒数 3·2·1。

**讲解页**：照片缓慢推近、奇偶语言方向相反；名字弹入（主角语言有闪白和揭晓铃）；拆段意思下面一条细金线；换步时整页平滑上推/下放，名字组保持可见。

**复盘（6 拍）**：「同一个东西 · N 种叫法」→ 每拍进来一行原生名字 + 字面 → `insight_links` 指定的段（如「袖」）高亮，`insight_langs` 的行亮金边 → 跨语言发现大字。

**结尾（7 拍）**：照片压暗模糊 →「不回看，你记住了吗？」→ 各语言名字模糊 → 评论框打字 → 最后 1.6 秒名字逐个清晰揭晓（描边）→ 收尾和弦。

## 猜选式 `--format quiz`（以 M009 为例，20.4 秒）

```
0 ─────────── 180 ─────────────── 378 ──── 486 ──── 612
│ 猜选 6.0s    │ 日语 6.6s         │复盘3.6s │结尾4.2s │
 选项1/1.5/2拍 倒数3拍 揭晓6拍
```

- **猜选（10 拍）**：第 0 帧 = 上半屏照片 + 两行问题（「「bridge 的名字」」+「{主角语言}里，它叫哪一个？」，字号 ≤80，不进按钮列）。第 1 / 1.5 / 2 拍依次滑入 A/B/C 三个选项（原生排版的名字 + 读音），第 3 拍「先猜一下」+ 右上圆环倒数，第 6 拍揭晓：闪白，正确项变金边、圆标变 ✓、框内右下角贴「就是它」；错误项压暗、划线，读音换成「其实是 · 那件东西 · 期号」。
- 选项：正确答案 + 同系列其他 2 期同语言的 `word`（`quiz.from` 可限定，按名字去重），按期号固定洗牌；字号 ≤88，按 600px 宽适配。
- **日语**：和讲解式的主角页相同，但只讲第 1 块重点、没有回忆步（刚猜过）。
- **复盘**：同讲解式。
- **结尾**：「你猜对了吗？ / 再记一遍：」+ 各语言名字回忆 + 评论框「我第一眼就选对了！」。

## 快闪式 `--format flash`（以 M009 为例，15.6 秒）

```
0 ── 54 ──── 126 ──── 198 ──── 270 ──── 342 ─────────── 468
│问题│ 中 2.4s │ 日 2.4s │ 英 2.4s │ 粤 2.4s │ 汇总 4.2s    │
```

- 所有换场都是**卡在拍点上的硬切**（`cut: true`，没有推镜），每次切入白闪 0.2 秒。
- **问题（3 拍）**：开场照片全屏压暗、慢慢拉远，问题切片浮在中间，两个「?」弹入。
- **每种语言（4 拍）**：该语言卡片的照片全屏压暗；语言章 +「01/04」；y=1060 起白色大字（≤210px，按 890px 宽适配）→ 读音 → 第 1 拍后金色拆段意思块（`parts[].m` 用「＋」连接；没有拆段用 `meaning`；放不下时字号 56→36 自动缩）。
- **汇总（7 拍）**：每行 语言章 + 名字（≤80px，按 720px 宽适配；行距 = min(128, 600/语言数)）依次进来 → 2.5 拍时 insight 金框 + 相关段变金 → 评论引导「你最先记住了哪一个？↓」。
- HUD 语言圆点保留；配乐从第 0 拍就进鼓。

## 图鉴式 `--format book`（以 M009 为例，43.2 秒）

```
0 ──── 126 ── 198 ─────────────── 612 ────── 828 ────── 1062 ──── 1170 ──── 1296
│ 封面 │ 中   │ 日（主讲 + 回忆）   │ 英       │ 粤       │ 索引    │ 记忆卡   │
```

- **时间线、每一步的起止、声音事件和讲解式完全相同**（prepare.py 直接沿用讲解式算好的场景，只把类型换成 `b_hook / b_lang / b_recap / b_outro`）。换场是翻书页（16 帧 ≈ 0.5 秒）：旧页以左边为轴翻走，新页在下面从暗到亮。顶栏的「中 日 英 …」语言圆点照常显示。
- **封面**：深色底 + 金色双线框；镶框标本照片（白边、胶带）先推近再拉开；下方「— 今日标本 —」和问题切片；第 3 拍「先猜一下」+ 圆环倒数。
- **词条页**（每种语言一页）：页眉「No.0N + 语言章 + 重点记/你熟悉的叫法 + N/总数」+ 双线；标本照片（基础高 300；页面下方有空时自动加高，最多 600，内容整体下移，下半屏不空着；加高量按整页各步的最小空位算一次，同一页内照片高度不变，贴剪报时页面不跳）；名字（原生排字，跨语言同词根的段下面一条细金线，约 0.4 秒从左往右画出）；读音；「词源」行（`parts` 用「＋」连起来，〈〉里是 `parts[].m`；三段以上的长名字按宽度自动缩字 46→32px）；「字面」行（`meaning`）；「参见」行（又见面了：这一段 ＝ 前面哪种语言的哪一段）。
- **重点**：每一步一块剪报：「① 标签」+ 原图切片（宽 ≤860，胶带、轻微倾斜）+ 注（`note`）。剪报一块块累积。放不下（底线 y=1580）时按顺序：① 先收起标本照片（整组上移 336）；② 再把前面读过的剪报折成一行「① 标签」；③ 最后才把当前剪报缩小（最小 0.62 倍，还放不下会 ⚠）。缩小后正文不足 34px 会 ⚠。
- **回忆**（主讲语言最后一步）：剪报全部折起（里面有答案），标本照片放回来当提示；一张便利贴盖住整条词条「？ 还记得它叫什么吗？」，到 `t_reveal` 时整张（不变透明）揭走，名字 + 放射短线；「重点记」标签回来。**只有主讲语言有回忆**，和讲解式一样。
- **索引页**：「索引 INDEX」+ `head`；每行 语言章 + 名字（≤84px，按 560px 适配）+ 点线 + 「p.0N」+「字面 · …」；到 `t_insight` 时同词根的段变金、相关行左边贴金色书签，下方「编者按」框里是 `insight`（44–60px，按 820px 宽适配）。
- **记忆卡**：「不回看，/ 你记住了吗？」→ 横线卡片「记忆卡 M.009」，每行语言章 + 模糊的名字（名字区宽 500，长名字自动缩字，不压 ✓ 章） → 评论框打字 → `t_reveal` 时逐行变清楚并盖 ✓ 章 → tagline。
