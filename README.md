## 直接给Claude的任务

> 请以本仓库为本轮唯一交接资料。先读项目策划案、参考项目与必要避坑、素材与工作环境，再逐张查看六张完整原图。独立设计并实际生成一版日物图鉴多语言竖版视频，不要只交计划或视频提示词。目标是系列统一、内容有用、手机易读、节奏自然、声音与内容合理承接。
>
> 不要寻找旧项目、旧视频、旧开发报告或历史聊天来恢复其他AI的答案。版式、配色、字体、镜头、动画、信息取舍与片长由你依据原图及目标决定；参考项目不是必须套用的视觉模板。
>
> 可选输入有现成配音和文本记录。先理解完整图卡，再决定是否复用；它不是完整原文，不应该决定你保留哪些内容或怎样分镜。音色评价暂缓，不要因此停止视觉制作。
>
> 有执行环境时克隆或下载本仓库，将源码与输出放在Claude工作区，保留可重复运行入口。交付实际MP4、源码/配置、素材映射、运行方法、取舍说明、真实自检及未验证项。检查最终编码文件的可读性、内容配对、节奏、音画对应、片尾和原图保护。
>
> 若当前环境只能读取文字、不能查看原图/音频或执行渲染，请明确说明具体缺失能力及需要转交的执行环境，不要声称已看图、试听或生成视频。

## 公开访问与Notion边界

当前仓库无需GitHub登录即可读取；原图和可选配音也公开可下载。公开可读不等于Notion/Claude已经成功检索内容。GitHub网页能显示这些图片，也不证明某个AI连接器能理解PNG或试听MP3。

按2026-10-12查阅的[Notion官方GitHub连接器说明](https://www.notion.com/help/notion-ai-connector-for-github)，该连接器有Business/Enterprise方案、组织侧及工作区设置要求；公开仓库并不自动完成连接器设置。本仓库已从个人私有仓库改为个人公开仓库，没有创建组织、迁移仓库或安装连接器。可以提供本页公开链接或下载文件交接；具体Notion/Claude环境是否可抓取页面、读图、读音频或执行代码，仍以真实能力及检查为准。

读取仓库资料不等于拥有FFmpeg/浏览器/代码执行能力。本仓库不保证Notion里的模型可以直接渲染MP4。
